# Вики-ЕГЭ

Каталог материалов для подготовки к ЕГЭ, который пополняют пользователи.
Материалы проходят модерацию, прежде чем появиться в каталоге.

## Возможности

- каталог материалов по предметам и номерам заданий;
- сортировка по полезности и дате добавления;
- добавление видео и статей с модерацией;
- лайки и жалобы на опубликованные материалы;
- административная проверка, редактирование, одобрение и подтверждаемое удаление;
- локальная база SQLite.

## Технологии и структура

- Python 3.10 или новее;
- Streamlit 1.66.0;
- SQLite из стандартной библиотеки Python;
- pytest для автоматических тестов.

```text
app.py                  Streamlit-интерфейс
db.py                   валидация, бизнес-логика и доступ к SQLite
wiki_ege.db             локальная база данных (создаётся при первом запуске)
.streamlit/config.toml  оформление Streamlit без секретов
tests/test_db.py        тесты базы на временных файлах
```

Файл базы и пользовательские данные не предназначены для публикации. При
первом создании новой таблицы добавляются три стартовых материала. Повторный
запуск инициализации не перезаписывает существующие записи и не добавляет
стартовые записи повторно в уже созданную, но пустую таблицу.

## Установка и запуск

В PowerShell из каталога проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

Откройте показанный Streamlit локальный адрес. Если используемая система
блокирует запуск скриптов PowerShell, активировать окружение необязательно:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Настройка администратора и секретов

Если пароль не настроен, административная панель отключена; пароля по
умолчанию нет.

Можно задать переменную окружения `ADMIN_PASSWORD` либо создать
`.streamlit/secrets.toml`:

```toml
ADMIN_PASSWORD = "длинный-уникальный-случайный-пароль"
```

Пример-шаблон находится в `.streamlit/secrets.toml.example`. Не помещайте
реальный пароль в исходный код, `config.toml` или репозиторий. Файл
`secrets.toml` исключён из Git. После изменения пароля перезапустите приложение.

Текущая авторизация использует один общий пароль для администратора, а не
персональные учётные записи или OIDC. Не используйте её как единственную
защиту для публичного сервиса с повышенными требованиями к идентификации.

## База данных и резервные копии

По умолчанию `wiki_ege.db` располагается рядом с `db.py`. Для размещения файла
в постоянном хранилище задайте абсолютный путь в переменной окружения
`WIKIEGE_DB_PATH`. Перед развёртыванием убедитесь, что выбранное хранилище
сохраняет файлы между перезапусками.

Для резервного копирования работающей базы используйте SQLite backup API,
который согласованно копирует файл даже во время работы приложения:

```powershell
python -c "import db; db.backup_database('backups/wiki_ege-backup.db')"
```

Каталог `backups/` создаётся при необходимости и вместе с файлами SQLite
исключён из Git; существующий файл назначения не перезаписывается. Проверяйте
восстановление резервной копии на отдельном файле до использования в рабочей
среде.

## Тесты

```powershell
pytest -q
```

Тесты создают отдельные базы во временных каталогах и не используют
`wiki_ege.db`.

## Известные ограничения безопасности

- Лайки и жалобы ограничены только состоянием текущей Streamlit-сессии; новый
  сеанс может проголосовать повторно. Без устойчивой идентификации пользователя
  надёжное ограничение повторных действий потребовало бы отдельного решения по
  учётным записям, хранению идентификаторов и миграции схемы.
- Жалобы могут быть накручены новыми сессиями; опубликованный материал после
  трёх жалоб переводится в очередь проверки. Не публикуйте сервис без
  дополнительной защиты от автоматизированного трафика, если это существенно.
- Ссылки ведут на внешние сайты. Проверяйте их вручную при модерации; приложение
  не загружает содержимое ссылок на сервер.
- Номера заданий заданы в коде и требуют сверки с актуальным кодификатором
  ФИПИ перед новым учебным годом.
